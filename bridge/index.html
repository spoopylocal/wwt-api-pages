Three steps to connect

  1. Extract and install

    Download the ZIP, right-click it and choose Extract All. Open the extracted folder and run Setup.exe. Choose your installation folder and whether to start at Windows sign-in. No separate Node installation or administrator access is needed.

  2. Load the Edge extension once

    Use your WWT Edge profile. Open edge://extensions, turn on Developer mode, select Load unpacked, and choose the extension folder shown in your setup guide. Sign in to ServiceNow. Sign in to MES only if you also use local scripts or the local dashboard.

  3. Connect your account

    Open the WWT-API Bridge desktop shortcut. Choose Connect shared dashboard, sign in with your invited account, then select Connect this bridge. Keep Edge running; the extension popup can stay closed.

Already installed?

Stop any active refresh, run the new Setup.exe into your existing MES-API folder, then click Reload on the bridge at edge://extensions. Your connection keys and saved data are preserved. Source checkouts are updated through Git instead.

Who can use it?

Anyone can download the installer. Shared dashboard access still requires an invitation, and MES and ServiceNow use each operator’s normal WWT permissions. If company policy blocks software or unpacked extensions, your IT team must approve installation.

The bridge runs in the background under your Windows account. MES and Salesforce dashboard refreshes run separately in the cloud; they do not need this installer.
